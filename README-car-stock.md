# إدارة المخازن والسيارات — دليل التشغيل على Windows

## المتطلبات

يحتاج النظام إلى **Python 3.10 أو أحدث** على Windows. نزّل Python من الموقع الرسمي:

<https://www.python.org/downloads/windows/>

أثناء التثبيت فعّل الخيار:

```text
Add Python to PATH
```

للتحقق من التثبيت، افتح **Command Prompt** واكتب:

```bat
python --version
```

إذا لم يعمل الأمر، جرّب:

```bat
py --version
```

## التشغيل

1. فك ضغط مجلد البرنامج في مكان مناسب.
2. افتح المجلد.
3. شغّل الملف `run_car_stock.bat` بالنقر المزدوج.
4. عند اكتمال التشغيل افتح المتصفح على:

```text
http://127.0.0.1:5000
```

يُنشئ ملف التشغيل بيئة Python محلية ويثبت الاعتمادات المطلوبة تلقائيًا عند أول تشغيل. اترك نافذة التشغيل مفتوحة أثناء استخدام النظام.

في المرات التالية شغّل `run_car_stock.bat` بالطريقة نفسها. لا حاجة لإعادة تثبيت الاعتمادات ما لم تُحذف البيئة المحلية.

## إيقاف النظام

ارجع إلى نافذة التشغيل واضغط:

```text
Ctrl + C
```

## التفعيل

بعد انتهاء الفترة التجريبية، ستظهر شاشة التفعيل داخل النظام. انسخ **معرّف الجهاز** و**بصمة الجهاز** الظاهرين في الشاشة وأرسلهما إلى المطوّر عبر قناة التواصل المتفق عليها.

بعد استلام كود التفعيل المرتبط بهذا الجهاز، أدخله في حقل التفعيل واضغط **تفعيل النسخة**. لا تشارك كود التفعيل أو بيانات الجهاز علنًا، ولا تعدّل ملفات البرنامج يدويًا؛ فالتفعيل مرتبط بالجهاز وقد يحتاج إلى إصدار جديد عند الانتقال إلى جهاز آخر.

## قاعدة البيانات والنسخ الاحتياطي

يحتفظ النظام ببيانات المنتجات والسيارات والوارد والشحنات والمبيعات والمرتجعات والجرد في قاعدة بيانات محلية تُنشأ تلقائيًا داخل مجلد البرنامج.

لأخذ نسخة احتياطية يدوية، أوقف النظام أولًا، ثم افتح **Command Prompt** داخل مجلد البرنامج واكتب:

```bat
copy car_stock.sqlite3 car_stock_backup.sqlite3
```

يمكن أيضًا استخدام شاشة **النسخ الاحتياطي** داخل النظام. عند استرجاع نسخة، خذ نسخة احتياطية من البيانات الحالية أولًا؛ لأن الاسترجاع يستبدل البيانات الموجودة.

عند نقل النظام إلى جهاز آخر، أوقفه وانقل نسخة قاعدة البيانات فقط، ثم شغّل النظام على الجهاز الجديد واتبع خطوات التفعيل الظاهرة له.

## الأخطاء الشائعة

### لا يبدأ `run_car_stock.bat`

تأكد من تثبيت Python وتفعيل `Add Python to PATH`، ثم أغلق Command Prompt وافتحه من جديد. إذا استمرت المشكلة، شغّل:

```bat
python --version
```

وتأكد من وجود الملف `requirements.txt` داخل مجلد البرنامج.

### فشل إنشاء البيئة أو تثبيت الاعتمادات

تحقق من اتصال الإنترنت، ومن أن لديك صلاحية الكتابة داخل مجلد البرنامج. تجنب وضع البرنامج داخل مجلد محمي مثل `C:\Program Files`، ثم شغّل الملف مرة أخرى.

### تظهر رسالة أن المنفذ 5000 مستخدم

أغلق أي نسخة أخرى من النظام، أو ارجع إلى نافذة التشغيل واضغط `Ctrl + C`، ثم شغّل `run_car_stock.bat` مرة أخرى.

### لا يمكن فتح الصفحة

تأكد من أن نافذة التشغيل ما زالت مفتوحة، ثم افتح:

```text
http://127.0.0.1:5000
```

### لا يظهر منتج أو سيارة في القوائم

تحقق من شاشة **المنتجات** أو **السيارات**. العناصر التي تم حذفها من القائمة تُوقف مع الاحتفاظ بالحركات السابقة، ولا تظهر في قوائم الإدخال الجديدة.

### ظهرت شاشة التفعيل بعد تغيير الجهاز

هذا متوقع؛ التفعيل مرتبط ببصمة الجهاز. أرسل معرّف الجهاز والبصمة الجديدين إلى المطوّر للحصول على كود تفعيل مناسب للجهاز الجديد.

### فقدان البيانات أو تلف قاعدة البيانات

أوقف النظام فورًا، ولا تكتب فوق النسخة الأصلية. احتفظ بها، ثم استرجع آخر نسخة احتياطية سليمة من شاشة **النسخ الاحتياطي** أو انسخها إلى مجلد البرنامج بعد أخذ نسخة من الحالة الحالية.
